\section{Hierarchical IP Addressing \& Subnetting Strategy (Step 2)}

\subsection{VLSM \& Dual-Stack Design Methodology}
To prevent IP exhaustion while eliminating wasted address space on point-to-point infrastructure links, TVI adopts \textbf{Variable Length Subnet Masking (VLSM)} for IPv4 alongside hierarchical \textbf{IPv6 Dual-Stack} Global Unicast Addressing (GUA). Subnet capacities are strictly sized according to:
\[
    \text{Usable IPv4 Hosts} = 2^{(32 - \text{Prefix})} - 2
\]
Key sizing decisions follow four architectural rules:
\begin{enumerate}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Right-Sized Engineering \& Guest Subnets:} Large R\&D engineering departments at HQ (\texttt{\textasciitilde 400} hosts) and Hanoi (\texttt{\textasciitilde 350} hosts) receive \texttt{/23} blocks (\texttt{510} usable hosts), while Hanoi Guest Wi-Fi (\texttt{\textasciitilde 100} concurrent guests) is constrained to a \texttt{/25} block (\texttt{126} usable hosts). Executive/Finance (\texttt{\textasciitilde 150} hosts) and Da Nang Logistics (\texttt{\textasciitilde 200} endpoints) receive \texttt{/24} blocks (\texttt{254} usable hosts).
    \item \textbf{Zero-Waste Point-to-Point Links (\texttt{/30}):} Every router-to-router WAN link, HQ Layer~3 uplink, and GRE/IPsec tunnel is allocated an exact \texttt{/30} subnet (\texttt{2} usable host addresses).
    \item \textbf{Dedicated Out-of-Band Management (\texttt{192.168.x.0/24}):} Regional management VLANs (\texttt{VLAN 99}) use deterministic \texttt{/24} blocks separated from corporate \texttt{10.x.0.0/16} data planes to simplify Netmiko inventory targeting and management ACLs.
    \item \textbf{Hierarchical IPv6 Alignment:} Every IPv4 subnet maps 1-to-1 onto a dedicated \texttt{/64} IPv6 prefix carved from its regional \texttt{/48} site block (\texttt{2001:DB8:10::/48} for HQ, \texttt{2001:DB8:20::/48} for Hanoi, \texttt{2001:DB8:30::/48} for Da Nang), using valid hexadecimal identifiers (\texttt{2001:DB8:FFFF::/48} for WAN links and \texttt{2001:DB8:CAFE::/48} for VPN tunnels).
\end{enumerate}

\subsection{Centralized Infrastructure Services \& Loopback Identifiers}
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Centralized DHCP, DNS \& NTP Server (\texttt{10.10.10.50}):} Placed inside HQ \texttt{VLAN 10}. Remote user subnets (\texttt{HQ VLAN 20}, \texttt{Hanoi Gi0/1.20 \& Gi0/1.50}, and \texttt{Da Nang Gi0/1.30}) forward DHCP Discover broadcasts via \texttt{ip helper-address 10.10.10.50}.
    \item \textbf{OSPF Loopback0 Router-IDs (\texttt{/32}):} \texttt{HCMC-EDGE-RTR01} (\texttt{10.255.255.1}), \texttt{HCMC-DIST-SW01} (\texttt{10.255.255.11}), \texttt{HCMC-DIST-SW02} (\texttt{10.255.255.12}), \texttt{HANOI-RND-RTR01} (\texttt{10.255.255.2}), and \texttt{DANANG-LOG-RTR01} (\texttt{10.255.255.3}).
    \item \textbf{Layer~2 Switch Management Default Gateways:} Cross-WAN SSHv2 reachability from the HQ automation host is ensured via \texttt{ip default-gateway}: \texttt{192.168.1.1} on \texttt{HCMC-CORE-SW01}, \texttt{192.168.2.1} on \texttt{HANOI-RND-SW01} and \texttt{HANOI-RND-SW02}, and \texttt{192.168.3.1} on \texttt{DANANG-LOG-SW01}.
\end{itemize}
